Getting started

1. Calculate and verify

Choose a tool and replace sample values with project inputs. Read Method & scope and verify manufacturer requirements. Green confirms only the conditions checked by that tool.

2. Save alternatives

Select or create a project. For ducts, pipes, grilles, fittings and insulation, enter a name and add results to the schedule. Edit reloads inputs; Update saves the recalculated result. Do not sum parallel branches as one series path.

3. Reports and backups

View the report before exporting PDF; choose Save as PDF in the print dialog. PDFs are for reading/sharing; JSON files back up editable projects. Check the download succeeded, keep a copy and use Open file to restore. Saved results do not automatically recalculate when other tools change.
